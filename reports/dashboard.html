NSE Up / Sideways / Down direction model

Verified checkpoint state for the final-year project. Every number here comes from a self-test that passed on real adjusted price data, in the development window only — the April 2025 holdout is sealed.

For any NIFTY 100 stock, this system calls the next 10 trading days as Up, Sideways or Down, and is judged on what that call earns after real brokerage costs — not on how often it is right.

Nothing is modelled yet. Phases 0–2 built the data, the labels, the backtest engine and the baselines; the model itself is Phase 4. The first figure below — a Sharpe ratio of 0.90 — is what that model will have to beat.

What one prediction actually looks like

A label is not a guess about a price. It is the answer to: starting from this close, which happens first over the next ten sessions — a rise of 2×ATR, or a fall of 1×ATR? If neither, the answer is Sideways.

      Classification floor

      Each rule is long-or-flat, so against the triple-barrier labels it is a two-class Up / not-Up predictor. “Lift” is how much better than guessing it does — the best rule beats guessing by under 5%, which is how little a plain indicator knows about a 10-day move.

      Label balance by stock

      Triple-barrier outcomes over the development window. The barriers are deliberately asymmetric (+2×ATR up, −1×ATR down), so the nearer down barrier is struck first far more often — Down is the majority class in every stock. A long-only system therefore needs its 2:1 payoff to carry it, not its hit rate.

        The 8-stock pilot

        Chosen for maximum code-path coverage, not as a representative sample. That choice is why the pilot's own buy-and-hold beats the index, and why its CAGR is not evidence of anything.

        Purged walk-forward folds

        Expanding train window, one-year test window. A label stamped at t is resolved by prices through t+10 sessions, so any train label whose resolution window reaches into the test period is dropped — otherwise the model would be fitted on its own test data. That purge is only about ten sessions wide, so on a ten-year axis it is a hairline between each train bar and its test bar; the counts it removes are in the table below.
